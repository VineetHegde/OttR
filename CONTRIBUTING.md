# Contributing to OttR

Thank you for helping. Before your first contribution is accepted, please read
this page. It is short, and it matters.

## What you agree to

OttR is released under the OttR Open Connection License (see `LICENSE`).
Section 6 of that license says that when you submit a contribution:

1. Your contribution is licensed under the same license as the rest of OttR.
2. You also give the project owner, Vineet Hegde, a permanent right to use,
   modify, distribute and sublicense your contribution, **including under
   different terms**. In plain words: the owner may later release or sell your
   code under other licenses, including ones that are not open source and
   including as part of Sebrain AI.
3. You keep the copyright in your contribution.
4. You confirm that you wrote it, or have the right to submit it, and that it
   does not contain code you are not allowed to license this way.

If you are not comfortable with point 2, please do not submit code. Opening an
issue or a discussion is always welcome.

## How to confirm

Tick the confirmation box in the pull request template. A pull request without
the ticked box will not be merged.

## Other rules

- Do not copy code from other projects unless its license allows this and you
  say so in the pull request.
- Do not add dependencies without discussing them first. We check each one's
  license.
- Do not commit personal data (recordings, learned profiles, screenshots).
